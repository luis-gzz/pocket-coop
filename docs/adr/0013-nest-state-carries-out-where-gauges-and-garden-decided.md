# A nest state walks the hen to its lay target instead of laying instantly

ADR-0007 split laying into Gauges gating *when* and Garden deciding *where*, both resolved in the same instant the lay clock fires — the egg simply appeared at the chosen spot. That reads oddly once beds hold multiple eggs and a full bed can send the hen to a specific floor spot near it: a hen laying from wherever it happened to be standing, with the egg teleporting into a bed several tiles away, no longer looks intentional.

We're adding a third phase: the chicken's own FSM gets a `nest` state that walks the hen to whatever target Garden picked (an open bed slot, or a floor spot near the nearest full bed), then lays on arrival. Garden still owns the decision of *where*; the hen's state machine now owns *how* it gets there. The lay clock's refractory timestamp moves from "when the clock fires" to "when the egg actually lands," so a hen mid-walk can't double-fire. We considered keeping the egg's placement instant and only playing a cosmetic walk animation, but rejected it — Garden's target can go stale (a bed can fill up while the hen is mid-walk), and treating the walk as real state that can be interrupted or re-targeted is simpler than faking a walk to a decision that was already committed.
