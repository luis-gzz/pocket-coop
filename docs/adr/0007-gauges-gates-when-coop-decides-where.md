# Gauges gates when a hen lays; Coop decides where the egg goes

Egg laying needs the same clock-driven gate-and-chance pattern the poop clock already established on Gauges (a happiness gate, a refractory gate, a chance roll, all driven by the same `self.now`/`TimeScale` clock). But the egg's destination — the nearest open hen bed, near the closest bed if all are occupied, or a random spot if none exist — depends on state that isn't owned by any one chicken: all placed beds and all active eggs, which a future second hen would need to see too.

We split this instead of building one new module end-to-end: Gauges grows a lay-clock section mirroring the poop clock and emits a "laid" event; a new Coop module, owned once by `main.lua` alongside the one `Chicken` instance, holds every placed bed and active egg, decides placement, and is what persists on a lay, a collect, or a placement. We considered one module owning both halves, but rejected it — Gauges already owns every other per-chicken timer (satiety, cleanliness, poop clock, pet buff), and the WHERE half (bed selection, shared inventory) has nothing to do with any single chicken's clock, so pulling the lay-gating math out onto a separate module would break that precedent for no benefit.
