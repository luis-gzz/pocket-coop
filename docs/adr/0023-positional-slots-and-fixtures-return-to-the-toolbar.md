# Slots are positional, and fixtures can be taken back by dropping them on the toolbar

The inventory used to be two ordered lists: the toolbar, which put fixtures first and appended returned items, and the barn. It is now forty fixed slots: ten in the toolbar (always shown, empty or not) and thirty in the barn. Each item type sits in exactly one slot, and the player arranges them in the full-screen barn view by long-press drag, where a drop on an occupied slot swaps the two. We chose positional slots over auto-sorted lists so the player's arrangement is never reshuffled. The cost is an extra screen to manage items, replacing the old Store and Take out buttons.

Fixtures, which were permanent once placed, can now be taken back: drag one onto the toolbar band and it leaves the map. Items stay infinite, so there are no counts, and "stacking" a returned fixture means leaving its type where it already is. Only a type found nowhere takes a slot: the first open toolbar slot, else the barn. That landing slot, or the barn button, flashes so the player sees where it went. A returned bed's eggs are collected rather than dropped as floor eggs, since otherwise taking back a bed would litter the garden. Hens re-pick where to lay through the existing pause-and-retarget a bed drag already triggers.
